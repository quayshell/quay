# Quay

**A native macOS shell for coding agents — Claude Code and Codex — with per-account identities, worktree-isolated parallel agents, indexed session history, and attention surfacing.**

[![Website](https://img.shields.io/badge/Website-quayshell.com-blue?style=flat-square&logo=google-chrome&logoColor=white)](https://quayshell.com)
[![Discussions](https://img.shields.io/github/discussions/quayshell/quay?style=flat-square&logo=github)](https://github.com/quayshell/quay/discussions)
[![Stars](https://img.shields.io/github/stars/quayshell/quay?style=flat-square&logo=github)](https://github.com/quayshell/quay/stargazers)

Quay gives every project its own berth: Spaces that carry a real agent account, panels that exec the agent directly, parallel agents isolated in their own git worktrees, and a session history you can search. When an agent needs you, Quay says so — once, in one place.

## Install

Download from **[quayshell.com](https://quayshell.com)**. macOS 14 or later.

---

## Why Quay

- **Per-account identities** — a Space carries its own agent account, not a factory reset of your config. Switch clients without switching machines.
- **Parallel agents, isolated** — run several agents at once, each in its own git worktree, without them racing each other's builds.
- **Indexed session history** — every Claude Code and Codex session, searchable, with transcripts rendered as chat.
- **Attention surfacing** — one notch chip tells you which agent is waiting, working, or done. Answer questions without hunting for the terminal.
- **Quay Memory** — sessions leave a card behind, so a thread you dropped three days ago can be picked up.
- **Skills, projected once** — one library, symlinked into every agent, written by one writer that refuses what it doesn't own.
- **Native Swift** — no Electron. Everything stays on your machine.

## This repository

This is the community home for Quay: **bug reports, feature requests and discussions.** Quay's source is not public; this repo holds no code.

### Report a bug

[**Open a Bug Report →**](https://github.com/quayshell/quay/issues/new?template=bug_report.yml)

Include your Quay version (Settings → About), your macOS version, and which agent you were running. Attaching a diagnostic report (Settings → About → Export Diagnostic Report) makes most bugs diagnosable on the first reply — it's plain text containing no file paths, branch names, account names or transcript contents, so you can read the whole thing before you attach it.

### Request a feature

[**Open a Feature Request →**](https://github.com/quayshell/quay/issues/new?template=feature_request.yml)

Describe the problem you're solving, not only the solution you want.

### Ask a question

For usage questions, troubleshooting and general chat. Search first.
